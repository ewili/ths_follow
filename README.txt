股票同花顺跟单系统 使用说明
========================================

目录说明:
  signal-server/  - 喊单端（部署在喊单电脑上）
  follow-client/  - 跟单端（部署在跟单电脑上）

启动方法:
  1. 先启动同花顺客户端并登录
  2. 双击对应目录下的 start.bat 启动服务
  3. 浏览器访问:
     喊单端: http://localhost:8000
     跟单端: http://localhost:8100

注意事项:
  - 两端需分别部署在不同电脑上
  - 首次启动可能需要安装 VC++ 运行时（自动）
  - 确保同花顺客户端保持前台运行
  - 按 Ctrl+C 可停止服务
